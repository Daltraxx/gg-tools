# GG Tools

A collection of utilities and tools for automating tasks and workflows.

## Features

- Streamlined workflows
- Easy integration
- Modular design

## Installation

Clone the repository:
```bash
git clone <repository-url>
cd gg-tools
```

To make the tools available globally, you can install the package:
```bash
pip install .
```
or using pipx:
```bash
pipx install .
```

or use the tools directly from the source:
```bash
python -m mail_tools.update_image_urls
```
